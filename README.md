# 理论练习室

计算机程序设计员（四级 / 中级）理论知识练习网站。在线使用：https://ai.002231.xyz/

- 练习模式：300 道题按顺序作答，提供逐题解析；答对后 3 秒自动进入下一题。
- 模拟考试：随机抽取 100 题，交卷后统一判分。
- 游客可直接练习；登录后可保存练习进度、跨设备续练及查看已提交的历史试卷。

## 部署

使用 HTTPS、PHP 8（PDO SQLite、Argon2id）以及支持 PHP 会话的 Web 服务器。将本项目的站点源码部署到 Web 根目录，在该目录的同级创建 `private/sessions/`，并使 `private/` 及其会话目录仅对站点 PHP 运行用户可读写。SQLite 数据库会在首次使用时创建。根据实际容器路径调整 `.user.ini` 的 `open_basedir`；不要将 `private/`、Git 元数据或凭据部署在公共 Web 根目录内。

本仓库仅包含网站源码、题库和解析，不含线上账号、练习记录或会话数据。
